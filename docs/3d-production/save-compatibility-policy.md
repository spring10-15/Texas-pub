# 桌面存档兼容与升级约定

2026-10-03，适用于当前 Godot 桌面预览，不适用于网页存档。

## 已实现的行为

存档是 Godot 用户数据目录中的 `three-d-checkpoint.save`；目录由 `OS.get_user_data_dir()` 决定，不在安装目录。应用名 `Godot德扑酒馆` 和用户目录设置应保持稳定，避免升级后找不到旧档。Mac/Windows 各自保存，不自动同步。

`SaveStore.VERSION` 为 1。封装包含版本号、状态字节和 SHA256 摘要，摘要用于发现损坏，不是反作弊。写入同目录临时文件、读回验证后才替换原档；已处理的失败路径清理临时文件。

加载同时验证文件与游戏语义，包括资金、物品、牌局、行动队列、筹码、RNG 和世界位置。有效档恢复后暂停等待继续，不重复买入或领奖。文件损坏、版本不同或语义不兼容时保留原档、关闭本次自动覆盖并提示，不静默重置资产。

## 当前兼容边界

| 变化 | 当前处理 | 限制 |
|---|---|---|
| 模型/材质更新 | 状态不保存网格，通常可延续 | ID、物件状态与空间坐标须保持；建筑搬动后的安全位置另测 |
| 牌桌名称/描述/奖励描述变化 | `table_definitions_compatible()` 忽略明确列出的相关字段，恢复使用当前定义 | 不表示任意规则变化都兼容 |
| 部分后增 Run 字段缺失 | 对 restore 中明确列出的字段补默认值 | 其他字段和类型仍必须通过校验 |
| World 缺少 props 字段 | 按空字典恢复默认开关状态 | 未记录的旧动画进度无法补回 |
| 必需牌局字段、规则数值或 ID 不兼容 | 拒绝恢复、保留文件 | 同为 v1 不保证可读；没有独立内容规则版本号 |
| 封装版本不是 v1 | unsupported_version、提示并保留 | 没有任意版本迁移器，不支持读取未来版本 |

本版不承诺全部历史档兼容。早期缺少行动控制字段的在途牌局可能被拒绝，不能修改金额/牌面来绕过校验。

## 升级执行约定

1. 美术批次保持玩法和 ID。搬动场景前列出玩家旧位置、返回位置、物件状态的兼容处理，并验证真实旧档夹具。
2. 改封装或必需语义时明确版本变化。先备份原文件，再针对明确旧版转换；结果通过完整语义、资金/牌局/RNG对照后才替换。不能静默自动补钱或抹掉背包。
3. 在途牌局无法继续时，发布说明列明受影响版本/状态，默认保留原档并拒绝恢复，提供经过验证的兼容版本或转换。
4. 发行前用旧版实际生成的夹具测试藏匿点、搜索、消费、牌局行动中、抵押、预约及撤离结果，记录两版提交和包体哈希。新代码生成的新档不能证明旧版迁移。

这些是后续升级约定，不代表迁移器或全部历史夹具已实现。

## 证据与交付待办

当前资源包已验证同版跨进程 World 保存/恢复、读档暂停/继续、损坏原文件保留，以及四酒馆规则状态的磁盘恢复。详见 `desktop-export-status.md` 和 `output/builds/preview-restart-*.log`；夹具由当前版本生成。

待验收：历史发行包迁移、跨平台同档、Windows 默认用户目录、真实断电/磁盘写满、高精建筑改造后的恢复位置安全。

玩家遇到提示时先保留截图，关闭游戏，备份原存档和游戏包，反馈版本及最后几个操作；不要删除原档或手工修改牌局。开发侧用副本复现并交付验证过的恢复方法。

## 2026-10-03：角色变换损坏保护

角色位置和离座返回位置的 basis 必须是正常刚体旋转，不接受零尺寸、缩放或剪切。专项先复现四种异常被接受且改变世界，再修复为在替换 Run/道具/镜头前拒绝，恢复专项 71 项零失败；正常旋转、入座/暂停、旧可选字段恢复继续通过。此保护不迁移异常坐标、不改变资金，不新增封装版本。合法角色由游戏控制器产生单位比例旋转；外部手工缩放角色的存档不属于兼容承诺。

## 2026-10-03：实际旧包至新包恢复检查

verify_preview_upgrade.py 从保留的 TexasPub-before-transform-fix.zip 提取旧 release PCK，以旧包 World 保存入口分别生成藏匿点及活动牌桌夹具；独立新进程加载更新后的 TexasPub.zip 内嵌 PCK，用新包 World 恢复。四次生成/恢复进程全部退出 0，位置、视角、物件、牌桌/筹码/RNG、读档暂停及继续均通过；两份旧夹具首末 SHA256 一致。

证据目录 output/builds/upgrade-checks/20261003-125601/ 保留两份旧包生成的 .save、四份日志和报告。报告记录旧新 ZIP、内嵌 PCK、脚本和夹具哈希，旧新 PCK 不同；报告 SHA256：`33d485032f95bcc8058bc174e4f1c1b0f11500aaf90e42e7bf709ba604f85457`。

这是本次升级的两种同 v1 状态兼容证据，运行方式为 Mac 编辑器加载发行资源包，不是原生真人重启，不覆盖全部历史版本、消费/抵押/预约/撤离结果夹具或 Windows。未修改正式玩家存档。

旧包升级检查扩展为四种状态：藏匿点、活动牌桌、实际搜索事件后、实际购买后。搜索选择由旧包可用事件产生，购买从旧包当前货架的合法物件中选择；没有直接赋值库存或资金。旧包生成四份存档、新包逐份恢复，8 个进程全部通过，完整世界快照包含搜索结果、行动力、现金、背包和 RNG，原始夹具首末哈希一致。最新证据 output/builds/upgrade-checks/20261003-125808/report.json。抵押、预约、撤离结果和其他历史版本仍待验证。
