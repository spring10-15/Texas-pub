# 德扑酒馆：Windows 内部试玩版

2026-10-03 更新，Windows x64 预览构建，已包含存档异常变换矩阵保护。尚未在 Windows 真机启动验收，人物和场景美术仍在精修。

## 启动

完整解压 ZIP 到普通文件夹，保持 TexasPub.exe 和 TexasPub.pck 在同一目录，然后双击 TexasPub.exe。不要在压缩包里直接启动，也不要只复制 EXE。本版无需安装 Godot 编辑器。程序未签名，请仅使用项目方提供的包。

## 操作与第一局

WASD 移动，鼠标观察，E 与准星指向的物件交互，B 打开背包，Esc 暂停。面板内用鼠标点击按钮。

从藏匿点打开出发面板，选择酒馆并确认。先探索和搜索，再到货运桌入座、确认买入；按照可用按钮行动，完成后离座。找到出口，查看费用并确认撤离，返回藏匿点检查金库。背包只显示已拥有物品和已知线路。四桌逐步解锁，不必打完全部牌桌才撤离。

正常游戏自动保存，重新打开后恢复进度并暂停，点击继续。退出时关闭游戏窗口，游戏会先尝试保存；若出现保存失败提示，请保留窗口并反馈。存档损坏时游戏会提示并保留文件，请反馈提示内容，不要反复覆盖原文件。

## 反馈

告诉我们：能否启动；哪个画面或操作出问题；退出再开是否回到原进度；牌局和撤离的资金是否看懂；是否卡顿或看不清路。截图或出问题前的最后几个操作最有帮助。

已检查：官方模板版本和 SHA512；导出无引擎错误；包内资源、四酒馆四桌、预约/紧急撤离及独立账目。资源检查使用 Mac 上的 Godot，不能代替 Windows EXE 的运行验证。未验收：Windows 图形驱动、真实窗口、30 分钟稳定性、全部特殊通行证路线、干净机器首次启动。
