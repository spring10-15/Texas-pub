# 3D 样板计划复核与本版测试指南

更新：2026-09-08。本记录是当前 3D 制作入口；根目录 development-plan.md 保留网页版本历史。

## 引擎与美术分工

继续采用 Blender + Godot，无需换引擎。Blender 负责场景、道具、人物、材质和动画；Godot 负责走动、交互、牌局、经济、撤离、保存与游戏打包。现有皮箱已经通过 Blender → GLB → Godot 实际运行。

[Blender 官方 MCP](https://www.blender.org/lab/mcp-server/) 已安装，实际读取了项目源场景的 1,479 个对象。它帮助自动操作 Blender，不代替游戏引擎，也不自动把高模变成适合实时运行的资产。安装证据见 blender-mcp-installation.md。

[Godot 官方格式文档](https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_3d_scenes/available_formats.html) 推荐 glTF 2.0，也支持通过 Blender 导出器导入 .blend。项目继续保留可编辑 .blend，向 Godot 交付 .glb，便于稳定复现；骨架和动画一同走 glTF 流程，最终仍需逐个资产验证。

## 本次已完成的玩法范围

沿用此前确认的藏匿点、烟雾酒馆、货运桌和账房地窖样板范围。不是四种酒馆的完整美术成品。

- 双桌下注、AI、全押与边池、盈利奖励、带钱出发和贵重物折现。
- 九种可用道具全部有规则：标记镜片、镇定酒、袖口夹、信号打火机、玩家笔记、一次性手机、后厨通行证、码头通行证、夹层钱包；商店分轮上架。
- 普通出口、预约接应、后厨楼梯、河边接驳、丢现金、丢贵重物，共六类出口；预约有两种接应方案。三种特殊入口已有实体交互点。
- 预约先付预付款，撤离再付尾款；到期和风声限制均有效。通行证使用后消耗，线索与预约随存档保留。
- 风声达到 6 时，当前牌桌结算并离座后自动执行可用的最优撤离；无可用出口则失败结算，夹层钱包可保留至多 80 现金。
- 自动保存资金、背包、路线、牌局、随机数、位置和镜头；兼容上版存档，重启后暂停等待继续。

与网页规则的两处明确取舍：手机提前到第二轮上架，使两桌样板能在最后一桌前使用；封锁自动撤离按现金加贵重物的最终到账选最优路线，避免只比较现金而丢掉更高价值物品。未改动网页版本。

## 计划中需要补齐的工作包

| 工作包 | 要做什么 | 验收方式 |
|---|---|---|
| 高精度美术到运行资产 | 高模制作后做低模、UV、材质烘焙；分离活动门、箱盖和交互道具，检查单位与轴心 | Godot 近景检查、碰撞与交互回归、真实帧率测量 |
| 人物 | 概念、建模、拓扑、骨架、权重、坐姿和发牌/下注/反应动画；对手差异和状态驱动 | 同一角色在 Blender 与 Godot 的外观、骨架和动作一致，无穿桌或坐姿漂移 |
| 材质与灯光 | Blender 程序化/Cycles 材质不能按原样保证实时效果；烘焙 PBR，调整 Godot 灯光和曝光 | 按参考图对比，检查暗部、金属、玻璃与文字可读性 |
| 表现与反馈 | 入座、奖励、撤离短过渡，声音、对手动作与结算反馈 | 玩家无需解释就能知道拿到什么、付了什么、为什么结束 |
| 剩余完整游戏内容 | 完整搜索事件、抵押系统、第三/四桌及另外三种酒馆的路线和空间 | 本双桌样板体验确认后，再逐项迁移与测试；不把配置存在等同于玩法接通 |
| 性能与交付 | 制定实际设备性能预算、LOD/贴图规格，安装导出模板、Mac/Windows 打包 | 长时间运行、完整存档回归和各平台独立启动；当前尚未验收 |
| 素材资料 | 校正协作 CSV 剩余缺列，保留来源/许可证据；逐图确认高模参考 | 标准 CSV 解析无错列，引用文件存在，未测项明确标记 |

优先顺序：本版逻辑试玩 → 根据试玩修正可读性与节奏 → 精修两个样板空间和人物 → 达到约定画质后扩展场景。高精度美术不与全部玩法扩张同时铺开。

## 你可以这样测试

1. 启动 Godot/three_d/启动3D原型.command；有存档时按“继续探索”。WASD 行走，鼠标观察，E 交互，B 背包/服务，Esc 暂停。
2. 在藏匿点对准房门按 E，确认带钱出发。购买道具会消耗行动力，每轮只有 2 点，完成牌桌后刷新。
3. 第一轮在货架买后厨通行证，按 B 使用；再走大厅后勤通道，左转上楼到“后厨楼梯”出口，查看费用并撤离。
4. 另开一局，到货架买镜片或笔记，完成货运桌；第二轮可买打火机、钱包、袖口夹、手机或码头通行证。按 B 查看自己物品的使用条件。
5. 完成货运桌获得接应线索后可预约；接应出口会显示预付和尾款。也可继续账房地窖，再比较各路线到账金额。
6. 在牌局中途关闭窗口、重新启动，检查现金、手牌和位置恢复。测试不会主动重置已有存档。

本版画面仍是粗模，未加入正式人物和音效；启动依赖本机 Godot，不是独立安装包。
