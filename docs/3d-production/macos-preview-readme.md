# 德扑酒馆：Mac 内部试玩版

2026-10-03 更新：已包含存档异常变换矩阵保护。人物和场景美术仍在精修，本包用于内部试玩。

## 启动

完整解压 TexasPub.zip，双击 Godot德扑酒馆.app，无需安装 Godot。程序尚未签名或公证；若 macOS 阻止启动，请反馈系统提示。不要直接在压缩包内启动。

## 操作与第一局

WASD 移动，鼠标观察，E 与准星指向的物件交互，B 打开背包，Esc 暂停。面板内用鼠标点击按钮。

从藏匿点打开出发面板，选择酒馆并确认。先探索和搜索，再到货运桌入座、确认买入。按照可用按钮行动，完成后离座；找到出口告示，查看费用并确认撤离，回到藏匿点检查金库。四桌逐步解锁，不必打完全部牌桌才撤离。

正常游戏自动保存，重新打开后恢复进度并暂停，点击继续。关闭游戏窗口时会先尝试保存；保存失败请保留窗口并反馈。存档损坏时会提示并保留文件，请反馈提示内容。

## 反馈与验证范围

反馈能否启动、操作是否看得懂、资金和撤离费用是否清楚、退出再开是否恢复、哪里卡顿或看不清路。出现问题时记录最后几个操作或截图即可。

本机已验证原生包启动及短时窗口运行。当前 30 分钟巡回使用 Godot 引擎加载 PCK，并非此原生包的长时验收。尚未完成干净机器首次启动、中端机器性能与最终高保真美术验收。

本版修正连续鼠标转向后微小旋转误差造成存档被误判损坏的问题；明显缩放、剪切及无效矩阵仍拒绝。
