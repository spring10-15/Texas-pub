# 高精度美术建模执行计划（交给高级模型）

2026-09-29。健哥已亲自走完现有场景，暂未发现 bug，并同意开始下一步高精度建模准备。本文件是**执行任务书**，不是美术完成声明；本轮只制定计划，不生成图片、不改模型。玩法状态转移分母、真人对照与目标设备性能仍未验收，故 Phase 1 和 Phase 3 均不能据此标为通过。美术可按已稳定的内容 ID 和交互锚点并行制作，避免先改玩法规则。

## 目标与边界

用 Blender 5.2 可编辑工程制作高模，整理游戏低模、UV、烘焙 PBR 材质与动画，经 glTF/GLB 导入 Godot 4.7。交付对象是**可游玩的实时资产**，不只是一张离线渲染图。最终覆盖藏匿点 + 四家酒馆共五个宏观空间、八位对手与酒保共九人、九件可用道具与十件贵重物共十九件、五类灯光氛围。四家酒馆各含现有的货运、账房、镜厅、余烬牌室与多高度撤离翼；“四桌房间”不能误算成“四家酒馆”。

保持 `Godot/three_d/rules/content.json` 的资产 ID、已有房间解锁、买入、路线价格、出口条件、存档结构和交互结果不变。美术改动可调整视觉网格、材质、镜头与表现层；如必须移动碰撞体、射线锚点、门、楼梯或出生点，应先列出受影响的游戏坐标与回归用例，再作为单独的集成改动处理。不能用一张贴图或换色冒充四家独立建筑，也不能为了近景质量把离线高模直接当运行网格。

已有参考优先用 `assets/scene-plates/`、现有 `.blend`、游戏截图和 `docs/3d-production/external-handoff/B2-production-breakdown/` 的逐件清单。部分场景板的内容适用性与授权尚未逐张核实：可用于内部方向比较，**不得未经确认直接嵌入发行纹理**。如确实缺少某个角色、贵重物或空间的必要参考，先写明缺口、现有素材为何不足及拟生成图的具体用途，等健哥确认后才调用 image2.5 生图；不要预先批量生成。

### W0 已核对的技术接缝（2026-09-29）

- 当前 Godot 项目入口是 `Godot/project.godot`，视口配置为 1376×768、Forward Plus、Mac Metal、Windows D3D12、3D MSAA 2×。这只是配置，不是实测帧率。
- 当前开发机为 MacBook Pro（Mac17,2，Apple M5，24 GB 内存，内屏 3024×1964）。它可做本机基线；不能据此声称目标「中端 Mac/Windows」已过 60 fps。高级模型需记录目标测试机实际型号、游戏分辨率与画质档，再定可执行的面数/贴图/灯光预算。
- `world.gd` 的 `build_stash()` 使用 `stash.glb`，通过 `CaseLidPivot` 查找皮箱盖；台灯、窗户、抽屉、牌、筹码的状态和可点击范围在 `scene_props.gd` / Godot 节点。`build_tavern()` 给货架、牌桌、搜索点、座位与出口建立物理/交互节点，`install_detail()` 只隐藏原可视网格并装入 `tavern-detail.glb`。新 GLB 必须与这些锚点对齐，不能让视觉门挡住射线或可走空间。
- 后勤三翼的路径、斜坡、楼梯平台和出口交互在 `tavern_layout.gd`；角色加载与 `idle/bet/win/fold` 动画映射在 `characters.gd`。先从这些源文件导出锚点表，再定建模坐标和角色动作命名，避免靠截图估位置。
- 当前各 GLB 磁盘大小可作包体初始记录，不能代替显存或运行性能：藏匿点约 16 MB、酒馆细节约 11 MB、交互道具约 5.7 MB、路线细节约 0.8 MB、九人物每人约 2.5 MB。W0 的性能基线仍需实机采样；本次没有测量帧时。

## 每批统一交付与验收

每个工作包交付时附：①源 `.blend`（可编辑对象、清晰集合命名、纹理打包或可重建路径）；②生成/导出脚本与 Godot 使用的 `.glb`；③资产 ID → Blender 对象 → GLB 节点 → Godot 使用点的对应表；④三张以上固定视角截图，至少一张为**Godot 实际运行**而非 Blender 渲染；⑤三角面/网格数、贴图尺寸与显存或包体变化；⑥该批涉及的交互、存档、空间和角色回归结果。生成脚本不得覆盖手工精修源而无备份/确认；若改导出方式，要明确哪一份是权威源。

近景模型应同时有细节源和实时运行版；资产预算由 W0 的目标硬件基线决定，不能拿“对象数少”代替 GPU/CPU 帧时间，也不能只拿单帧截图声称 30 分钟稳定。任何批次若出现碰撞错位、出口不可达、牌面难读或角色遮挡重要 HUD，先修到可玩再放行下一批。
