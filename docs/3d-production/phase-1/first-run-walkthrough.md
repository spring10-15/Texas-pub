# 首次完成一局：烟雾酒馆安全撤离路线

适用于当前开发版，目标是理解完整循环并把剩余钱带回金库，**不保证赢钱**。未计时、未完成五人外部试玩；不能当作 Phase 4 的 <5 分钟教程验收。

1. 双击 Godot/three_d/启动3D原型.command，或在 Godot 打开 project.godot 后运行。
2. 本路线只适用于藏匿点且没有活动局的起点。若读档进入酒馆或其它未结束状态，先完成、撤离或放弃当前局并回到藏匿点，再开始本路线；无需删除存档。
3. 在藏匿点用 WASD 行走、鼠标观察，朝房门走近，准星对准门按 E。
4. 在出发框选择“烟雾酒馆”，查看带出本金和撤离费，确认带钱出发。金库不足时界面会明确显示试玩资金重置，重置须由你自行决定。
5. 在大厅入口附近找到白色“出口告示”，对准按 E，先记下普通出口。
6. 按 B 查看已知路线的费用、舍弃财物和预计到账，再关闭背包；未知特殊路线不会列出，此处只做预览，不会远程撤离。
7. 可在房间后方左角柜子按 E 查看搜索选择，先不领取物件；查看不消耗行动力。
8. 走到牌桌前沿，对准按 E 入座，阅读买入 60、盲注 10/20、最多两手。
9. 点击“开始牌局”，确认随身现金减少、筹码进入牌桌。
10. 轮到你时按信息决定；不懂局面可弃牌止损，有免费过牌机会可过牌。不要为了试按钮而全押，也不必购买道具才能继续。
11. 观察中央输赢提示、筹码净变化与公开牌；若未终桌，点击“下一手”。
12. 本桌结束点击“离开牌桌”，检查剩余筹码已返还现金。获奖会提示，输牌也可撤离。
13. 暂不继续高买入房间，返回大厅入口门，按 E 打开撤离确认。
14. 阅读现金、手续费、贵重物和最终到账。若路线不可用，不会直接扣款；可返回查看其它已知路线。必要时明确查看放弃损失，不要把失败当作普通撤离。
15. 普通出口可用时确认付款，返回藏匿点，核对金库与本局净变化；这才是完成一局。
16. 用窗口关闭退出后再启动，核对金库保存。不要删除存档文件来验证。

下一局可以尝试：购买情报工具、比较带贵重物撤离与先出售、预付接应费、在风声上升前安排降风声。这些是可选策略，不是强制的新手任务。

自动验证边界：`smoke.gd` 与 `table_integration.gd` 已从实体交互和牌桌 HUD 跑过出发、开桌、结桌、出口告示与撤离；后者还用隔离临时存档核对了第 16 步的重启后金库和防重复到账。它们不测玩家是否看得懂提示、是否能自主找路，也不提供真人计时或首局教程通过证据。
