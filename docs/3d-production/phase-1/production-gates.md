## 2026-09-21 目标复核与执行顺序

五阶段范围和验收门槛保持不变。当前优先收口 Phase 1，不因基础资产已经存在而宣布进入高保真制作。主 Agent 继续承担规则、架构、集成及后续 Blender 工作；外部 Agent 由用户安排，负责证据复核与资料整理。

1. 修复已证实的问题、过时测试夹具；未复现线索保持待查，不据此修改玩法。
2. 补全状态转移目录的剩余族，再做同版本覆盖汇总；截至 2026-09-25 已登记 357 个结果，仍不是完整分母。
3. 按[固定种子对照试玩](fixed-seed-playtest.md)组织新老手同路径对照：只计至少两个合法玩法选项中成功执行、改变状态的有效决策事件，主指标为两人事件总数绝对差 >3。多样性按每酒馆、每组连续 100 个正整数种子，统计「房间连接、五阶段货架、首个固定路线 ID」的不同组合；X=50，要求严格多于 50 种。三组独立窗口的最小实测为 72 种，见 [种子与有限池](seeded-pools.md)。正常局从确认出发计时至完成撤离，包含探索、购物、阅读和决策；首桌时长另记。
4. Phase 1 通过后验收 Phase 2 的内容矩阵，随后制作 Phase 3 的高保真空间、人物与道具。新生图仍先向用户确认必要性。
