# 一晚跨酒馆：规则与证据

2026-09-14。实现使用整晚四张牌桌、最多十手的共享进度；玩家完成当前酒馆至少一桌后，可以换店继续尚未完成的牌桌。这样跨酒馆选择改变费率、货架和路线，同时保持短局的手数上限。四家酒馆和四种桌规的所有组合继续可达，真人 20–30 分钟节奏尚未验收。

## 转场的明确代价

从大厅普通出口的结算界面选择“继续去下一家酒馆”。确认前显示当前普通出口费、固定车费 15、总额、扣后现金、1 行动力消耗、保留风声、下一店普通出口费率与额外风声。原预约结束且预付款不退，新店的出口和本地路线需要重新发现。该按钮不会出现在背包的远程路线预览里。

需要当前普通出口可用、已完成本店至少一桌并离座、还有尚未完成的晚间牌桌、有足够现金和行动力。仅能去本晚未访问的酒馆；刚抵达不能继续跳店。一晚最多四家、三次转场，访问更多酒馆是可选策略，并非要求每局绕完全部酒馆。

## 状态如何衔接

| 状态 | 转场结果 |
|---|---|
| 金库、本金基线 | 不变；财物尚未落袋 |
| 现金、行动力 | 扣显示总费和 1 行动力 |
| 背包、风声、本轮已降风声标志 | 保留 |
| 已完成桌、搜索次数/结果、桌序、剩余手牌种子、对手 | 保留，不重开或重抽 |
| 已知桌规、对手笔记 | 保留，与整晚固定桌规/对手一致 |
| 货架与初始接应方案 | 根据原种子和目的地生成，使用当前全局阶段 |
| 公共出口、本地路线线索、原预约 | 清除；不能把上一店预约用于新店 |
| 房间连接与事件布局 | 保留整晚计划 |
| 存档 | 保存访问顺序、抵达时完成桌数、逐次转场费用与原有完整状态 |

普通出口是本批转场的唯一入口。特殊撤离仍用于回金库；特殊路线接续其他酒馆尚未设计。各店仍共享灰盒与已有基础场景资产，不能计作四种独特建筑美术完成。

最终结算记录转场日志，并显示已扣转场总费；净变化以最初带出的本金为基线，不在中途重新计算。旧存档补当前店为访问起点，不自动发生转场。历史数组类型、重复酒馆、费用记录及抵达进度不一致会拒绝恢复。

## 已验证与未验证

venue_transfer_test 923 项通过，包括 12 个有向酒馆对的状态与存档检查，以及每对实际跑完四桌的一晚流程。完整流程使用合法的固定弃牌对手与主动降风声，从初始财富独立累计牌桌净收益、奖励价值、降风声费、转场费和最终撤离费，最终金库逐条相等。覆盖重复/旧版本请求、资金/行动力不足、风声封锁、本晚完成、访问记录/旧存档、真实转场 UI 和恢复地点。Metal 截图 output/3d/venue-transfer.png 已查看。

新增 `venue_order_test.gd`：四酒馆的 24 种访问顺序各实际打完一桌、执行三次连续转场并撤离。脚本使用 seed 0 的整晚计划和合法牌桌行动；对手固定弃牌，玩家可跟注则跟注。每轮只在下一桌预计风声达到 5 时付费降风声，每桌核对独立财富账本，每次转场后验证本地出口线索清空并做存档往返，最终核对三段旅程记录。该策略 24 条均完成，降风声、转场及最终撤离合计支出为 402–454，最终金库为 1661–1713。对照策略在每次能降风声时都付费，12 条完成、12 条在第四桌因随身现金不足 160 无法买入。

再取种子 1、17、97 与四种循环访问顺序，分别用被动过牌/跟注和胜率估算后的弱牌弃牌、强牌加注两种机械玩家策略，各跑 12 条真实 AI 四店路线。结尾从**已知且可用**的路线中选择预计到账最高者，按实际费用及舍弃财物核对总账。被动策略完成 3/12 条（均从紧急出口丢弃部分现金离开），6 条买入不足、3 条转场费不足；估算策略完成 0/12 条，8 条买入不足、3 条转场费不足、1 条风声 6 被迫结束。这说明四店长线在该小样本下高风险，不应被当成普通局的默认路径；估算策略在单桌平均收益更好，不代表四店生存率必然更高。

同样的 3 个种子 × 4 家酒馆，另做 24 条**留在同一家打四桌**的真实 AI 对照：被动策略完成 9/12 条，估算策略完成 8/12 条；各有 3 条屋顶会所路线在第三桌后风声 6 被迫结束，估算策略另有 1 条买入不足。两种打法在单店普通路径均可完成若干样本，但屋顶会所的风声压力特别突出。原始逐局的种子、玩家策略、终止原因、完成时路线与金库余额见 `output/3d/venue-order-matrix.json`。

这只是固定策略下四店路线的可达性与经济压力样本，不是所有种子/道具/输赢分支的守恒证明，也不是真人难度验收。全局状态转移覆盖分母与真人新老手差异仍需要验证。当前服务存档测试使用 seed 0 的镜片货架夹具，随机缺货由种子池测试覆盖。
