# 种子与有限池：第一批接入

2026-09-13。已实现每局固定货架计划、初始预约接应方案和四桌发牌种子；房间、事件、对手组合池以及跨酒馆流转仍待实现，不计作 Roguelike 最小版完成。

正常出发生成一次正整数种子。每个阶段从该酒馆原有货架中移除一种可选工具，保留原本供应的镇定酒、玩家笔记和一次性手机；第二阶段仍保证手机。不同种子改变可买工具而非仅改变排序。工具缺席影响当轮策略，但不会取消普通出口或基础降风声服务。首个预约方案从该酒馆两条已有接应方案选取，之后沿用付费刷新/预约规则；特殊路线的可用性与费率没有随机化。

规则层 start 的 seed_value=0 是测试用完整货架基线；真实出发界面传入随机正整数。variant_plan 保存五阶段货架、四桌种子、初始接应索引与版本。查看商品不消耗随机状态；实际入座取预先保存的牌局种子，不再按入座时间换牌。显式测试种子仍可覆盖牌桌入口。

旧存档缺少计划时沿用原固定货架和历史入座行为，不在读档时重抽。新计划随存档保存；恢复时检查版本、货架物品范围/重复/基础用品、牌桌种子范围及接应索引。实际牌局中的 RNG 仍由原有 table_checkpoint 保存。
