## 复核与修正

协作代码提供了购买、卖出、降风声、规则情报及三件道具的规则草稿，尚无场景入口或测试。实际运行发现数据导出键名与读取键名不一致，开局即报 searchActions 不存在。已统一为 items / shops / searchActions / inventorySlots，并重新从 src/data.js 导出。

此外修正道具动作与物品 ID 的匹配检查，补充贵重物按 value 出售、盈利奖励、满包提示及撤离折现。未删除或覆盖 inventory/ 文档原稿，其复核仍见 inventory-review.md。

## 当前功能

- B 打开背包/酒保服务，或通过吧台射线交互。购物、出售、规则情报、付费降风声各消耗行动力；每阶段 2 点，完成一桌后刷新。库存上限 6 格。
- 标记镜片记录下一张公共牌；袖口夹只能在翻牌前首次行动前替换第二张手牌，并保留此前镜片预测的公共牌；镇定酒降低风声。已消费物品与本桌使用记录均保存。
- 第二桌使用桌面道具额外增加 1 风声。开着服务面板时停止 AI 和玩家下注，关闭后继续。
- 两张桌只有净盈利才领奖。货运桌优先象牙筹码；已有该物品时按原版筹码阈值选择袖扣/打火机。账房地窖 130 及以上为珍珠项链，否则翡翠胸针。选择规则对应 src/game.js 的 pickTableReward。
- 贵重物可出售，也会在普通撤离时按 value 折现；现金费率只作用于现金。满包明确提示未带走奖励；离桌和重载不能重复领奖。
- 普通撤离不可用时，可选择查看放弃损失，再明确确认；清空随身现金与物品、到账为零、原金库保留。此为当前灰盒避免卡局的手动损失出口，不冒充原版完整追缴或特殊撤离演出。

## 保存行为

存档文件为 Godot 用户数据目录下的 three-d-checkpoint.save，独立于网页存档。每 0.5 秒检查变化，切出窗口和关闭时也保存。正常关闭会写入最近状态；强杀可能丢失最后半秒进度。存档包含金库、随身现金、库存、规则情报、行动力、道具记录、完整牌桌私有状态与 RNG、房间、位置、观察角度和座位状态。存档不是公开给 HUD 的数据，也不是反作弊机制。

写临时文件后验证，再替换旧档；原始整数、向量与变换保留。恢复不会再次扣买入、发牌或结算，进入暂停界面等待继续。文件损坏或版本不兼容时保留原文件并停用本次覆盖，界面提示；不静默重置玩家资产。写入失败时显示提示，正常关闭请求不会悄悄丢弃尚未保存状态。
