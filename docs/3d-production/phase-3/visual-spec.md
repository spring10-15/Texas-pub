# Phase 3 美术规格：W0 工作版

2026-09-29。本版把已实现的镜头/交互尺度与现有参考图转成 W1 样板的制作约束；它是**待实机样板校准的规格**，不是五空间美术完成声明。视觉选择服从「场景提示下一步行动、风险可读、一个晚上的 noir 短局」。新图生成仍须先向健哥说明必要性并获得确认。

## 镜头、尺度与构图

| 项目 | 当前游戏基线 | W1 制作约束 |
|---|---|---|
| 单位和房间 | Godot 以米计；基础房壳宽 6 m、深 7 m、高约 3 m，后勤三翼在房壳外延伸 | Blender 源按米制、Y 向上导入后的世界坐标对齐；不移动现有可走地面和出口交互体来迁就模型 |
| 探索镜头 | 眼高 1.6 m、FOV 75°、交互射线 2 m、碰撞胶囊高 1.7 m / 半径 0.24 m | 在距物件 0.5–2 m 的常见观察位置检查轮廓与文字；可点击件不能被新装饰或玻璃挡住射线 |
| 牌桌镜头 | 座位相机位于牌室局部 `(-0.45, 1.42, 0.65)`，俯角约 0.38 rad，FOV 65° | 筹码、牌面、对手手部与输赢反馈在入座画面各有清楚层级；角色、吊灯和酒架不能遮住关键 HUD |
| 互动部件 | 皮箱盖按 `CaseLidPivot` 查找；抽屉、台灯、窗、牌和筹码在 `scene_props.gd` 单独控制 | 轴心、开合空间及明/暗、正/反等状态必须能在 Godot 运行画面区分 |

数据入口：`Godot/three_d/scripts/player.gd`、`world.gd`、`scene_props.gd`、`tavern_layout.gd`。建模前导出并核对锚点；上表中的房壳尺寸是**现状**，不等于所有房间必须长得一样。四酒馆需要各自的建筑语言，若要改变实体通行形状，应单独提出碰撞与路径集成改动。

## 五空间的视觉语言

| 空间 | 已核对的参考与主形 | 材质、灯光和信息重点 |
|---|---|---|
| 藏匿点 | `assets/scene-plates/藏匿点场景.png`：近景木桌、皮箱、台灯、雨窗；现有 `stash-runtime.png` 的镜头仍偏远，桌面小物难读 | 木纹、旧皮、纸张和黄铜由台灯暖光聚焦；窗外冷光给方向感。皮箱、桌面可翻牌与抽屉需在暗部仍可辨 |
| 烟雾酒馆 | `tavern-smoky-den-bg.png`：旧木、砖、绿罩灯、吧台和更深处的门；现有 `tavern-runtime.png` 已有可玩的桌/吧台/走廊 | 温暖但脏旧，烟雾只塑层次、不盖住出口告示或牌面。吧台货架的实物和酒保递物优先于墙面装饰 |
| 高层套房 | `tavern-high-rise-suite-bg.png`：石材、玻璃、皮椅与城市夜景 | 冷蓝城市光加受控暖灯；窗景强调高度，反射保持克制，桌面动作和可走门道不能被镜面吞掉 |
| 屋顶会所 | `tavern-rooftop-club-bg.png`：露台、栏杆、木地与串灯 | 参考图为日落，但游戏设定是同一晚；样板后续转为夜间城市天光与暖串灯，保留开敞感。栏杆与边界清楚，避免把可走出口做成假门 |
| 霓虹扑克俱乐部 | `tavern-neon-poker-club-bg.png`：蓝紫灯、深色镜面和多重桌位 | 保留赛博 noir 与当前规则中的数据节点闸门、传感器盲区、后台传送门等概念；具体设备外观先以路线规则和可玩空间为准。交互文字和牌面要从高饱和背景中脱离 |

这些场景板用于**内部造型方向**，不是可直接贴入发行资产的纹理来源；部分图的授权和适用性尚未逐张核实。每家酒馆应通过入口轮廓、天花高度/分区、材质组合和外部环境识别，而不是只换灯光颜色。现有后勤翼的平层、上行、下行空间关系在改建前必须保留；各酒馆按配置中的真实路线名称制作独立视觉，不能把烟雾酒馆的码头、楼梯外观复制给高层套房或霓虹俱乐部。16 条路线与现有图片的逐项匹配见[参考图筛查](reference-screening.md)。

## 材质与灯光的验收方式

- 木、皮、布、纸、石、玻璃、黄铜分别有符合尺度的粗糙度与磨损；磨损集中在扶手、桌缘、门把、箱角等接触位置，不能用一层全场均匀噪声代替使用痕迹。
- 高模用于倒角、缝线、雕饰、瓶口等近景源；运行版用低模、法线/粗糙度贴图与必要 LOD。纸币、卡牌与招牌只用游戏自有图形/字样，不从场景板照搬不可核实的标识。
- 五类氛围是藏匿点台灯/雨窗、烟雾暖灯、高层冷夜、屋顶夜风、霓虹湿街；最终亮度与雾量在 **Godot 实际画面**调，不以 Blender Cycles 预览为准。
- W1 固定三种距离（接近可交互物、普通行走、从门口看全景）各留 Blender 和 Godot 同视角对照。藏匿点验台灯开关、窗户开合、抽屉、牌与筹码；烟雾酒馆验桌面输赢、酒保货架、出口告示、上/下层路线。任一交互在画面中难发现或难读，先调整视觉层级，再增加装饰。

当前游戏的运行截图是 `output/3d/stash-runtime.png`、`output/3d/tavern-runtime.png`，是灰盒/基础资产基线。W0 还需补各空间固定视角截图、逐张参考图适用性判断及目标机型预算；W1 样板由健哥审看后才能锁定最终材质颗粒度与色彩脚本。
