# Phase 3 性能基线与待定预算

2026-09-29。目标仍是目标中端 Mac、Windows 上的游戏实测 ≥60 fps，以及连续游玩 ≥30 分钟无明显掉帧或内存增长。60 fps 对应每帧约 16.67 ms；这不是单个模型、GPU 或脚本可独占的预算。目标机型和画质档未确定，因此暂不分配逐资产面数/贴图/灯光上限，也不判定 Phase 3 性能通过。

## 可复测的本机起点

- 命令：`/Applications/Godot.app/Contents/MacOS/Godot --path Godot --script res://three_d/tools/perf_baseline.gd -- --test`。脚本以有窗口的 Metal / Forward Plus 启动游戏，先在藏匿点静止视角采样，再通过正常的出发动作到烟雾酒馆货运桌视角采样；每处预热 120 帧、记录 300 个渲染回调间隔。`--test` 关闭正式存档读取/写入和鼠标锁定。
- 环境：MacBook Pro Mac17,2，Apple M5，24 GB；Godot 4.7.2；游戏窗口/视口 1376×768；垂直同步模式 1。三次连续独立启动均退出码 0，场景切换成功。

| 场景 | 三次中位回调间隔（ms） | 三次 p95 回调间隔（ms） | FPS 监视值 | 渲染内存监视值 |
|---|---|---|---|---|
| 藏匿点 | 8.279–8.295 | 9.144–9.220 | 120 | 474,234,880 B |
| 烟雾酒馆货运桌视角 | 8.205–8.224 | 9.043–9.205 | 120–121 | 482,115,584 B |

这里测的是**静止视角的 Godot 渲染回调间隔**，可能受到 120 Hz 显示节奏、窗口调度和缓存影响；FPS 监视值也不是独立的 GPU 计时。内存字段仅为 Godot 报告的渲染内存，不代表进程总内存。此样本不能推出移动、灯光变化、四店切换、最重牌室、Windows 或 30 分钟稳定性。脚本每次覆盖 `output/3d/perf-baseline.json`；该文件是本地原始记录，范围以本页及脚本为准。

## W0 余下测量

高级模型选定目标 Mac/Windows 中端机型、显示分辨率和低/中/高画质档后，先用同一走位/镜头路径记录原版，再对每批高模资产重复。至少包含藏匿点近景、吧台货架、牌桌入座、后厨楼梯、河边坡道、四店切换；另以真实游玩持续 30 分钟记录 FPS 分位数、CPU/GPU 帧时和进程/渲染内存曲线。性能超预算时优化运行网格、材质、灯光和 LOD，再比较画质与可读性；不能用本页静态样本给最终资产放行。
