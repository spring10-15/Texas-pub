## C2-1 主指标改为「决策事件数绝对差 > 3」

- **修订前**：`real-player-protocol.md` §3 把"差异值"写成**待定**（"门槛用的是分歧**次数**还是分歧**率**尚未确认——本页不替主 Agent 决定"），并给了四个并列指标（决策机会数／实际动作数／选项分歧数／差异值）。

- **修订后**：示例重写——两位在 `OP-01` – `OP-06` 的**成功执行动作逐条一致**（`OP-03` 那一次被系统拒绝的「过牌」不改状态、不推进），分叉点落在**同一个 `机会ID` `OP-07`**（一方弃牌、一方加注 40）；`OP-07` 之后的每一行标 `分叉后（不配对）`。主指标 `abs(12 − 8) = 4` 与辅指标（可比局面 7、分歧 1）**都从 CSV 重算**，不再沿用旧 N。

### C2-R2 同路径示例不能换酒馆；原例改标「不合格对照」

- **修订前**：原示例声明走"烟雾酒馆 / 只打货运桌 / 普通出口"，但老手第 10 条写着"继续去高层酒馆"；还据此得出"同路径且差值未达标"。

### C2-R3 把「未作选择」与「执行拒绝/放弃命令」分开

- **修订前**：把"不买""不抵押"记成"成功执行"；又把"放弃"**整类排除**，只看文案里有没有这两个字。

### C2-R4 机会数、时刻与费用都要能重算

- **修订前**：协议要求"机会数"，但 CSV **缺** `机会ID` / 机会是否计入 / 关联尝试三列；`first-play-template.md` 缺**机会总数**；模板写「撤离**确认**时刻」；费用只写 `24 + 现金×12%（风声 5 时 +45）`——**只适用烟雾酒馆且省了向下取整**。
- **依据**：`routes.gd:11` `fee = flat + floor(cash × rate) + (45 if heat == 5 else 0)`；`routes.gd:51` `net = max(0, cash − fee − lostCash) + goods`；四家参数在 `content.json`。`T_extract` 是**撤离完成**，不是打开撤离框。
- **修订后**：
  - CSV 改为 **20 列**，新增 `机会ID` / `机会计数` / `关联尝试`；`机会计数` 只在某 `机会ID` 首行写「计 1 次」，重复行写「不计（同一机会的重复尝试）」并在 `关联尝试` 指回；**机会总数 = 不同 `机会ID` 个数**。
  - 模板补 `机会总数`、`可比局面数 / 分歧数`；`撤离确认时刻` → **`撤离完成时刻 T_extract`**；费用改为**通式**并附**四家酒馆参数表**，同时标明 `24 + 现金×12% + 45` 只适用烟雾酒馆、且省了 `floor`。
  - 模板新增一行「**本局金库落点 = 出发前金库 − 带出本金 + 最终到账**」。**这条纠正了一个实打实的算术错误**：原 CSV 写"金库 1200→1430"，等于在 `1200` 上加 `到账 230`，**漏了出发时已扣掉的 300 本金**；正确落点是 `1200 − 300 + 230 = 1130`（老手侧 `1200 − 300 + 189 = 1089`）。
  - 协议 §4.1 新增同一套通式与参数表；§5 的示例行数字全部换成**同一组虚构示例**（`N = 8`、机会总数 `9`、分叉 `OP-07`、可比 7/分歧 1），并注明**全项目只保留一组虚构示例**，避免多套数字互相漂移。
