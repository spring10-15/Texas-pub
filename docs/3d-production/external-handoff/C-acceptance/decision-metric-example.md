# 决策计数：一组**虚构**统计示例（附一组不合格对照）

> **⚠️ 本文件全部数字都是虚构的**，用于演示"这张表能不能算、分叉怎么标、排除项怎么排"。
> **它不是玩家数据，不是试玩结果，不能引用为任何验收证据。** 真实收数请用 `decision-record-template.csv`。

对应协议 `real-player-protocol.md` §3（主指标 `abs(N_new − N_experienced) > 3`）。

本文件分三块：

| 块 | 内容 | 能不能用来判断门槛 |
|---|---|---|
| §1–§3 | **合格示例**：两人同编号、同酒馆、同桌序、同撤离方式，分叉前**成功执行动作逐条一致** | 能演示算法，**不能**当体验证据 |
| §4 | **不合格示例**：原来的跨酒馆版本，**明确作废** | **不能**，连"达标/不达标"都不能判 |
| §5 | 计入分类规则：`未作选择` 与 `执行拒绝/放弃命令` 的分界 | 规则，不是数据 |

数据来源：本文件的示例与 `decision-record-template.csv` 顶部两组示例行是**同一组数据**。CSV 是原始记录，本文件是它的推导；`output/external-handoff/C2/verify_c2.py` 会从 CSV 把下面每个数字重算一遍。

## 0. 哪些数字可复算，哪些只能当记录值

| 类别 | 项 | 依据 |
|---|---|---|
| **可复算** | 决策事件数 `N` | 逐行数 `是否计入决策事件 = 是` |
| **可复算** | 机会数 | 该测试者出现过的**不同 `机会ID` 个数**（同一 ID 的重复尝试不重复计） |
| **可复算** | 主指标 | `abs(N_new − N_experienced)` 与 3 比 |
| **可复算** | 分叉时点 / 可比局面 / 分歧数 | `分叉标记` 列；只有 `分叉前` 与 `分叉点` 行可参与配对 |
| **可复算** | 手续费、到账、金库 | `routes.gd:11` / `routes.gd:51` + `content.json` 参数；金库 = 出发前金库 − 带出本金 + 到账 |
| **不可复算（记录值）** | 牌局内筹码与底池的逐手变化 | 依赖发牌与对手行为。本示例只把"离桌返还筹码"当**记录值**填，**不声称**能从中推导 |
| **不可复算（记录值）** | 计时 | 实际钟表时间，只有真人能填 |

> **本示例不做 20–30 分钟门槛判断**：路线只到第一桌（只打货运桌），按 `real-player-protocol.md` §4，单桌路线不能用来测 gate 6。

## 2. 主指标（门槛判定项）

```
P-A1（新手）N = 8      行 1、2、4、5、6、7、8、10 计入
P-A2（老手）N = 12     12 行全部计入

绝对差 = abs(12 − 8) = 4
判定   = 4 > 3 ？ → 是  →  主指标达标
```

**原始行数 ≠ `N`**：A1 有 10 行、A2 有 12 行，但 A1 的 `N` 是 8（排掉被拒 1 行、未作选择 1 行）。同一份账里 **机会数也不等于 `N`**：A1 机会数 9、`N` 8；A2 机会数 12、`N` 12。三组数都要原样留下，方便别人复算。

**阈值方向**（同一算式上的算术演示，不对应任何记录）：若 `N` 是 7 与 10，则 `abs(7 − 10) = 3`，`3 > 3` 不成立 → 未达标。

**达标 ≠ 体验成立**：还要看两人的**理由与复盘**。若 A1 的 8 条里有若干条写着"不知道还能做什么"，那是"没看懂"；如果写的是"我故意只做必要动作"，那是**策略选择**。两者必须分开写。

## 3. 辅指标（只能解释，不能替代）

### 3.1 配对规则

1. 配对的键是 **`机会ID`**，不是序号。
2. 只有 `分叉标记` 为 `分叉前` 或 `分叉点` 的行可以配对；`分叉后（不配对）` 的行**一律不配对**。
3. 同一 `机会ID` 有多行时（被拒 + 重试），用**成功执行**的那一行参与配对。

### 3.2 可比局面（本例：OP-01 – OP-07，共 7 组）

| 机会ID | P-A1 选择 | P-A2 选择 | 是否分歧 |
|---|---|---|---|
| OP-01 | 只抄下接应线索 | 只抄下接应线索 | 否 |
| OP-02 | 开始本桌 | 开始本桌 | 否 |
| OP-03 | 跟注 20 | 跟注 20 | 否 |
| OP-04 | 过牌 | 过牌 | 否 |
| OP-05 | 过牌 | 过牌 | 否 |
| OP-06 | 过牌 | 过牌 | 否 |
| OP-07 | 弃牌 | 加注 40 | **是** |

```
可比局面数 = 7
选项分歧数 = 1        （只落在分叉点 OP-07 那一条）
分歧率     = 1 / 7 ≈ 14.3%（分母是可比局面数，不是原始行数 10 / 12）
```

> **辅指标不能替代主指标**：本例主指标是 "4 > 3 达标"，分歧率是 14.3%——两个不同量纲。分歧率只回答"差异出现在哪一个决定上"。
> 也**不要**把分母写成 10 或 12（原始行数）——那些里含被拒行与分叉后无法配对的行。

**一个结构性事实（重要）**：按"分叉点 = 第一个不同的决定"的定义，**分叉点之前的每一条配对必然一致**（不一致就成了新的、更早的分叉点）。所以分歧数只可能由分叉点那一条贡献，分子最大是 1。这正说明**分歧率不能当门槛用**——它在结构上就几乎恒等于 `1 / 可比局面数`。

唯一例外是两个不同选项导致**同一状态**（例如两个入口通往同一面板）。遇到这种要在 `复盘` 里注明，否则一律按"第一处状态差异即分叉"处理。

### 3.3 分叉之后

- 分叉之后**不再逐局面配对**：A1 弃了第 2 手、A2 打到了摊牌，两人的牌、底池、行动力都不同，A2 的 OP-08 – OP-12 在 A1 的记录里**没有对应局面**。
- 分叉之后的记录**仍然计入各自的 `N`**（决策事件本身是真的），只是不参与配对。
- 所以 `分叉标记` 这一列**必须填**：没有它，事后分不清哪些行能配对。

## 4. 不合格对照（作废）

原稿给过一组"两人同编号、同路线"的示例，**已作废**。它错在五处，留在这里当反例：

| # | 问题 | 具体 |
|---|---|---|
| 1 | **首条即分歧，却把分叉标在第 7 条** | 第 1 条两人一个"跟注 20"、一个"加注 40"，状态从第 1 条起就不同；第 7 条之前的"配对"都不是同一局面 |
| 2 | **分叉后仍按同局面比较** | 把老手的第 8 / 9 / 12 条继续与新手第 8 / 9 条并列统计 |
| 3 | **路线不同** | 老手第 10 条写着"继续去高层酒馆"——两人已不在同一条路径上，主指标失去可比性 |
| 4 | **分类错** | 把"不买""不抵押"记成"成功执行"；又把"放弃"整类排除 |
| 5 | **选项不是真实选项** | 写"领取外套"，而货运桌的真实选项是「拿银打火机 · 1 行动力，风声 +1」与「只抄下接应线索 · 1 行动力」（`search_events.gd:4`） |

**结论**：这种记录**既不能判达标、也不能判不达标**——它连"同路径同局面"这个前提都没成立。原稿据此写的"绝对差 3、未达标"**作废**。

## 5. 计入分类：把"没做"和"做了"分开

判断依据是**有没有发生一次被系统接受的、改变状态的动作**，不是文案里有没有"放弃 / 不买"这些字。

| 情形 | 怎么记 | 计入 `N`？ |
|---|---|---|
| 在 ≥2 个合法玩法选项中点了其中一个，系统接受了 | 正常行 | **是** |
| 点了但被系统拒绝（不合法 / 条件不足） | 填行，`是否成功执行 = 否`，写清拒绝依据 | 否。同一 `机会ID` 可重试，**机会仍只计 1 次** |
| 打开面板 / 看了选项后关闭，**没点任何可点项** | 观察记录：`是否计入决策事件 = 否`，`不计入原因 = 未作选择` | 否（机会 +1） |
| 点了明确的拒绝 / 放弃命令**并成功执行**，资金或状态确实改变 | 正常行 | **是**。例：确认「放弃本局」→ `run.gd:458` `abandon()`：`vault += min(80, 现金)`、清空背包，是真实决策 |
| 镜头、纯移动、翻页与开关面板本身、自动发牌、AI 动作 | 不记 | 否 |

**两个容易写错的边界**：

- **"不买"不是一次成功执行的交易。** 关闭服务面板、不点购买按钮 → 记为 `未作选择`，不计 `N`（示例：A1 的 OP-08）。
- **"放弃"不能整类排除。** 文案里带"放弃"两个字不构成排除理由；要看它是不是一次真的、被系统接受的、改变状态的动作。

## 6. 这份示例证明了什么、没证明什么

| 项 | 说明 |
|---|---|
| **证明了** | 这套字段**能算**：排除项能标、分叉点能记、`N` / 机会数 / 主指标 / 可比局面 / 分歧数 / 手续费与到账都能从记录里重算出来，且主指标能算出"达标"与"不达标"两种方向 |
| **没有证明** | **任何真人体验结论**。数字全为虚构；没有一个真人被试；没有计时；没有截图 |
| **仍然缺的** | 真实被试（≥1 对同编号的新老手）、真实计时（`T_start` → `T_extract`）、真实截图、两人的理由与复盘 |
| **作废的** | §4 那组跨酒馆记录，以及由它得出的"未达标"结论 |
