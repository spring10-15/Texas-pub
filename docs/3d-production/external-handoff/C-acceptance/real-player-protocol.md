## 2. 相同种子 / 相同路径的对照设置（已可用）

**启动方式**：双击 `Godot/three_d/固定种子试玩.command`，输入约定编号（直接回车 = `20260922`）。细节见 `docs/3d-production/phase-1/fixed-seed-playtest.md`。
该入口**不读、不写、不覆盖正式存档**；关闭即丢弃本次进度。**真人试玩不要加 `--test`**。

| 项 | 要求 |
|---|---|
| 代码版本 | **同一 `git rev-parse HEAD`**，写进记录 |
| 种子编号 | **显式指定同一个正整数**（不是"随机"），写进记录 |
| 路径 | 同一酒馆 + 同一桌序 + 同一撤离方式；**两位测试者必须选同一家酒馆** |
| 起始条件 | 对照模式新启动金库 **1200**、出发携带 **300**；**不要**点"重置试玩资金"（会改掉金库，使两人起点不同） |
| 启动纪律 | **一位结束后关闭窗口，下一位重新双击启动并输入同一编号**；不要在同一窗口开第二局 |
| 对照配对 | 老手 1 名 ↔ 新手 1 名，**同编号同路径**；其余人可自由试玩 |
| 模式自检 | 进入藏匿点后顶部必须出现 `对照试玩 · 编号 … · 本次不读写正式存档`；**看不到就不是对照模式**，记录作废 |

### 2.1 相同种子**不能**保证后续局面相同（C2 新增，重要）

同编号只控制**起始条件**——货架、首个接应方案、对手名单、事件布局、发牌种子。
**从第一个不同决定开始，后续状态与 RNG 消耗就会分叉**（两人的牌、底池、行动力、风声都会不同）。

因此：

- **不要把两人的第 N 条决策记录当成"同一个局面"**——那只是编号相同，局面未必相同。
- **分叉点 = 第一处不同的 `选择`（成功执行的那个）**。分叉点的定义就是"从这里开始状态不同"，所以**首条就不同就首条标分叉**，不要往后挪。
- 每条决策记录都要写**前置状态**（手牌/底池/欠注/行动力/风声），并**标出分叉时点**：把 `分叉标记` 填成 `分叉前` / `分叉点` / `分叉后（不配对）`。
- **配对的键是 `机会ID`，不是序号。**
- 两种配对各有用处，**分开统计、不要混算**：
  - **同路径对照**：比较**总决策事件数**与整体风格差异（主指标用这个）。
  - **逐局面配对**：只在 `分叉前` 与 `分叉点` 的行上做，且要求**两个 `机会ID` 相同、`前置状态` 相同**；**分叉之后的行一律不配对**（两人的牌、底池、行动力、风声都已不同）。

## 3. 决策差异计数（**口径已由主 Agent 定死**）

### 3.1 主指标与辅指标

| 类型 | 指标 | 定义 | 用途 |
|---|---|---|---|
| **主指标（门槛用这个）** | **决策事件数绝对差** | `abs(N_new − N_experienced) > 3` | **门槛 5 的判定项**。N 是两人**各自**的"有效决策事件"总数 |
| 辅指标 | 选项分歧数 / 分歧率 | 在 `分叉前` + `分叉点` 且 `机会ID` 相同的行上，两人选了不同选项的条数，除以**可比局面数**。**分叉之后不配对** | **只能解释差异，不能替代主指标** |
| 辅指标 | 选择内容 | 每一条实际选了哪个选项 | 供复盘解释"差异出现在哪类决定上" |
| 原始量 | `N`、机会总数 | 两人各自的原始计数，必须原样保留 | 便于他人复算，不要只交一个差值 |

- **不允许**把门槛改成"分歧率"，也**不允许**换成别的次数口径。`production-gates.md` 门槛 1 的原文就是"新老手同路径决策差异 >3"。
- **分歧率在结构上就很弱**：分叉点定义为"第一处不同的决定"，所以分叉点之前的配对**必然一致**，分歧数最多是 1（分子只可能由分叉点那一条贡献）。这本身就是不能用它当门槛的理由。唯一例外是两个不同选项导致同一状态，遇到要在 `复盘` 里注明。
- **差异达标 ≠ 体验成立**。差值只是**必要条件**：仍需**玩家自述理由与复盘**说明差异从何而来（是"新手没看懂"还是"老手有策略"）。

### 3.2 计数单位（一条 = 一个事件）

**计入**：玩家在**至少两个合法玩法选项**中做出、且**成功执行**的一次选择。

**判断依据是"有没有发生一次被系统接受的、改变状态的动作"，不是文案里有没有"放弃 / 不买"这些字。**

**不计入**（逐项列出，避免记录者各算各的）：

| 不计入的动作 | 原因 |
|---|---|
| 被拒绝的动作（点了但系统拒绝 / 不合法） | 没有"成功执行"。**同一 `机会ID` 可重试，机会仍只计 1 次**（重试行在 `关联尝试` 里指回那条被拒行） |
| 重复点击同一个已执行的动作 | 同一次决策重复上报 |
| **未作选择**（打开面板／看了选项后关闭，没点任何可点项） | 没有发生动作。记为观察记录，`不计入原因 = 未作选择` |
| 镜头操作（转视角、缩放） | 不是玩法选择 |
| 纯移动（`WASD` 走位） | 不是玩法选择 |
| 翻页 / 打开关闭背包或面板本身 | 只是查看，不是选择 |
| **自动发牌** | 系统行为，不是玩家选择 |
| **AI 对手的动作** | 不是玩家选择 |

- **一次决策 = 一条事件**。**不得**写"实际动作数必然不小于机会数"——拒绝、重复、未作选择都会让实际执行数**小于**机会数。
- **`机会ID` / `机会计数` / `关联尝试` 三列必须填**：每个不同的 `机会ID` 在**首次出现的那一行**写 `机会计数 = 计 1 次`，同一 ID 的后续行写 `不计（同一机会的重复尝试）` 并在 `关联尝试` 指回首行。**机会总数 = 不同 `机会ID` 的个数**（含未作选择与被拒绝的机会）。
- **"放弃"不能整类排除**：若玩家点了明确的放弃 / 拒绝命令**并成功执行**，且资金或状态确实改变，那**是**一次决策。例：确认「放弃本局」→ `run.gd:458` `abandon()` 执行 `vault += min(80, 现金)` 并清空背包 → **计入 `N`**。
- 反过来，**"不买""不抵押"本身不算一次成功执行的交易**：所谓"不买"通常是离开面板，属 `未作选择`，不计 `N`。只有真的点了购买 / 抵押按钮并被系统接受，才算。

### 3.3 可记为决策的典型位置

**记实际出现的合法选项**：**选择哪家酒馆**、**开桌（买入，资金与风声都会变）**、**下注/跟注/加注/弃牌/过牌**、**是否使用道具（用哪件）**、**是否抵押（抵押哪件）**、**搜索事件选哪一个**、**服务面板是否真的买下某件道具**、**撤离路线与时机**、**是否继续去下一家酒馆**。

> 记选项时要写**游戏里真实出现的文案**。例：货运桌搜索点出来的两条是「拿银打火机 · 1 行动力，风声 +1」与「只抄下接应线索 · 1 行动力」（`search_events.gd:4`）——不要凭印象写成"领取外套"这类不存在的选项。

> **已删除的错误决策点**：初版把"**是否照搬默认本金**"列成决策点。**出发本金当前自动取 `min(300, 金库)`，没有手动选择本金的功能**（`run.gd:61`），那不是玩家决策。已删除。

## 4. 正常局的起止时间

| 时刻 | 定义 | 记在 |
|---|---|---|
| `T_start` | **确认出发**（金库已扣本金、场景切到酒馆） | `walkthrough-checklist.md` 第 4 步 |
| `T_table_start` | 首桌开始（**另记一栏**） | 第 10 步 |
| `T_extract` | **撤离完成** | 第 16 步 |
| **一局总时长** | `T_extract − T_start` | — |

- 用实际钟表时间（`HH:MM:SS`），**不要用视频时长倒推**。
- `T_extract` 记的是**撤离完成（付款完成、回到藏匿点）**那一刻，**不是**打开撤离框的时刻。`first-play-template.md` §1 的栏目名与这里一致。
- **单桌安全路线（17 步清单）不能用来判断 20–30 分钟门槛**：它只到第一桌，通常远短于正常局。要测门槛，另跑"打满本店可打的桌 / 跨酒馆"的路径。
- "正常局 20–30 分钟"与 Phase 4 的"首局教程 <5 分钟"是**两个指标**，分开计时。
- **对照模式下不要拿第 17 步验证读档**：固定种子模式不读写存档，该观察点不适用。

### 4.1 撤离费用与到账（记账要对得上）

```
手续费 = 当前酒馆平费 + floor(现金 × 当前酒馆费率) + (风声恰为 5 ? 封锁附加 : 0)      # routes.gd:11
到账   = max(0, 现金 − 手续费 − 舍弃现金) + 贵重物价值                                # routes.gd:51
本局后金库 = 出发前金库 − 带出本金 + 到账        # 出发时已扣本金（run.gd:61），不要重复加
```

| 酒馆 | 平费 | 费率 | 风声恰为 5 时的封锁附加 |
|---|---:|---:|---:|
| 烟雾酒馆 smoky-den | 24 | 0.12 | 45 |
| 高层酒馆 high-rise-suite | 42 | 0.18 | 70 |
| 屋顶酒馆 rooftop-club | 28 | 0.13 | 60 |
| 霓虹酒馆 neon-poker-club | 34 | 0.14 | 55 |

- `24 + 现金×12% + 45` **只适用烟雾酒馆**，而且**省掉了向下取整**（`floor`）。跨酒馆必须按上表换参数。
- 风声 ≥ 6 时普通出口直接封锁、**不出报价**；封锁附加只在风声**恰好等于 5** 时加。
- 记账时以**界面实际报价**为准，公式只用来判断"是否算错"。
