# 任务 A6：对手策略差异矩阵与复核

## 目标

用当前正式版 `output/3d/difficulty-probe.json` 中的同局面快照，量化八名对手在相同牌面、牌力估计、合法动作和随机值下的选择差异，找出最容易混淆的角色组合。此任务只整理证据，不修改游戏规则或生产参数。

## 输入

- `output/3d/difficulty-probe.json`
- `Godot/three_d/rules/content.json`（核对角色 ID、性格和策略参数）
- 当前 `HEAD` 和 `Godot/three_d/rules/opponent.gd`（报告中记录版本）

先确认探针报告有 448 个桌局结果、`failures` 为空，并读取 `repeatedRaiseContexts` 的实际条数。若输入文件缺失、运行失败或和当前生产源码版本对不上，停止分析并说明原因，不要复用旧数字。

## 执行步骤

1. 为八名对手生成 8×8 同局面动作分歧矩阵。每一对角色仅在相同快照上比较，分母须是两者都能合法选择的快照数；明确报告分歧次数、分母和比例。
2. 分别统计全部快照、玩家至少加注两次的快照、玩家至少加注三次的快照；另按牌桌、街道和行动空间大小分组，标明小样本分母。
3. 对每个角色给出动作分布（弃牌、过牌、跟注、加注、全押）及样本量；列出最相似的 5 对、最不同的 5 对，并附代表性快照 ID 或原始行号。
4. 对现有 `calm-widow` 与 `house-viper`、`smiling-knife`、`river-shark` 的相似问题复算，解释差异是否来自角色策略，还是合法动作/局面分布。
5. 独立复核当前自动化生成路径，记录 Godot 命令、执行时间、退出码、日志路径、输入文件 SHA-256、源码 commit。不要为了凑更好的数字删掉失败样本或改变过滤口径。

## 交付物

- `docs/3d-production/external-handoff/A6-opponent-differentiation/README.md`：结论、口径、限制、复现命令、源码 commit 和输入哈希。
- `docs/3d-production/external-handoff/A6-opponent-differentiation/pairwise-matrix.csv`：28 对角色的分歧计数、有效分母、比例及分组字段。
- `docs/3d-production/external-handoff/A6-opponent-differentiation/action-distribution.csv`：各角色动作次数、比例、局面类别与样本量。
- 如需脚本，放入同目录 `repro/`，保证只读现有报告并可重复生成 CSV；脚本不得改写生产源码或探针输入。

## 验收标准

- 八个角色均出现，28 个无序角色对均有结果；分歧分母仅包含双方都能做出选择的相同快照。
- 原始快照总数与输入报告吻合；各组分母可由 CSV 重新求和。
- 角色 ID、动作名和参数能对应当前 `content.json` 与 `opponent.gd`。
- 结论区分“自动样本下行为不同”与“真人可识别”；不得据此宣称已通过真人试玩或 Phase 1 门槛。
- 不提出未经测试的生产参数改动，不提交游戏代码。
