# A6 对手策略差异矩阵复核

复核日期：2026-09-24。源码基线：`fa94722aba20a05040804fc98d42acb1cbca645d`。本报告只比较同一快照下八名策略的反事实选择，不修改玩法，也不证明真人能辨认角色。

## 样本与口径

从当前 `output/3d/difficulty-probe.json` 读取 448 个桌局结果，失败数为 0；其中有 **85 个**同局面重复加注快照。输入探针只记录玩家加注次数至少为 2 的 AI 决策，因此“全部快照”和“玩家加注至少 2 次”是同一组 85 个样本；加注至少 3 次的子样本只有 11 个。不能把它解释成不受筛选的真实对局分布。

每个快照包含同一牌面、牌力估算、合法动作与随机值；将这组输入分别交给八名当前策略作选择。两名角色的分母是双方都在该快照上给出合法动作的行数。分歧率 = 不同选择行数 ÷ 共同有效行数。CSV 按总样本、重复加注次数、牌桌、街道及合法动作数量分组；样本量保留在每行，便于重算。

## 结果

在 85 个重复加注快照中，最相似的五对是：账房先生 / 河道老鲨 **5/85（5.9%）**、灰烬走私客 / 笑面刀 **6/85（7.1%）**、灰烬走私客 / 河道老鲨 **7/85（8.2%）**、庄家毒蛇 / 账房先生 **7/85（8.2%）**、庄家毒蛇 / 笑面刀 **8/85（9.4%）**。差异最大的五对是：沉静寡妇 / 绒衣新客 **39/85（45.9%）**、笑面刀 / 绒衣新客 **31/85（36.5%）**、庄家毒蛇 / 绒衣新客 **28/85（32.9%）**、灰烬走私客 / 绒衣新客 **25/85（29.4%）**、码头吹牛客 / 账房先生 **25/85（29.4%）**。

沉静寡妇与庄家毒蛇 **11/85（12.9%）**、与笑面刀 **11/85（12.9%）**、与河道老鲨 **21/85（24.7%）**。这说明同一输入下仍有相似组合；其中与庄家毒蛇、笑面刀的动作差异低于多数角色对。至少加注三次的 11 个快照里，这三对分别只有 **0/11、1/11、1/11** 个分歧；样本太少，不能据此推断该子场景里的稳定差异。

这些是**反事实动作分布**：多个角色在同一批定向筛出的状态上选择，并非每名角色各自独立进行的随机实战样本。先前专属重复加注反制参数在这批条件化样本中有可见动作差异，但普通玩家/生产 AI 对局仍未自然产生足够的连续加注输入。可见性和“性格独立可识别”仍要靠真人盲测判断，不能由这些比例代替。
