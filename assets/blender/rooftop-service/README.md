# 屋顶服务走廊与上行楼梯间首版

build_service.py 构建独立 Blender 源 rooftop-service.blend，并导出 Godot/three_d/assets/rooftop-service.glb。10,980 三角形、4 材质/合并网格，复用既有三张灰泥纹理，无新增 AI 图片。源保留修改器；导出应用变换。

覆盖入口与横向连接走廊、后厨准备区地坪、上行十二级钢楼梯、高处平台及楼梯塔顶部。新增钢扶手、防滑条、墙侧管线/管箍、通风百叶和门框。保留共用模型的木饰面、黄铜踏步收边、厨房设备、门扇与其他路线细节。

地坪顶面 0.014m，高处平台 1.214m；各踏步顶面比原碰撞级高 0.014m。模型只供视觉，不添加碰撞、灯光或交互。Godot 仅在屋顶替换对应旧粗模的可见网格，保留碰撞与触发点，其他酒馆恢复旧网格。

库房、装卸侧翼与屋顶河岸的建筑关系尚未独立完成。磨损、LOD、材质/灯光最终统一和性能门槛亦未验收。此模型不代表整个后勤区或屋顶高保真完工。
