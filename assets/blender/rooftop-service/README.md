# 屋顶后勤模型首版

build_service.py 构建独立 Blender 源 rooftop-service.blend，并导出 Godot/three_d/assets/rooftop-service.glb。当前 21,720 三角形、5 材质/合并网格，复用三张灰泥和三张胡桃木纹理，无新增 AI 图片。源保留修改器，导出应用变换。

覆盖入口与横向连接走廊、后厨准备区地坪、上行十二级钢楼梯、高处平台及楼梯塔顶部，以及中央库房、两只板条箱、后壁金属货架和预约货梯门。门框、栅门、把手、呼叫按钮与实际侧墙撤离点对应。

地坪顶面 0.014m，高处平台 1.214m；各踏步顶面比原碰撞级高 0.014m。模型只供视觉，不添加碰撞、灯光或交互。Godot 仅在屋顶主酒馆显示后勤模型；其他牌桌房间没有后勤通道。旧模型对应的可见网格隐藏，碰撞与触发点保留，其他酒馆恢复旧网格和 StoreDetails 装饰。

共用路线源 tavern-routes.blend 未覆盖；export_routes.py 将货梯和箱件装饰拆出 StoreDetails。旧几何总三角形和材质集合、整体边界不变。

装卸侧翼与屋顶河岸的建筑关系尚未独立完成。磨损、LOD、材质/灯光最终统一和性能门槛亦未验收。此模型不代表整个后勤区或屋顶高保真完工。
